# 🎬 YouTube Clone

A responsive front-end clone of YouTube built using HTML and CSS. This project replicates key UI elements of YouTube including the video grid, sidebar, modal popups, and responsive layout.

---

## 🚀 Features

- 📺 Video grid layout with thumbnails and metadata
- 🧭 Sidebar navigation with icons
- 🪟 Modal implementation using pure HTML & CSS
- 📱 Responsive design with media queries
- 🎨 Modular CSS structure for scalability

---


---

## 🛠 Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- No JavaScript (modal built with checkbox toggle)
